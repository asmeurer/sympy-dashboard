SymPy contributor dashboard

This dashboard is private. It loads its code and data from the asmeurer/sympy-contributor-dashboard repository, so you need a GitHub token that can read that repository.

Which token works?
  • The token of a logged-in GitHub CLI: gh auth token, or a classic token with the repo scope. Collaborators need one of these, because GitHub only lets you create fine-grained tokens for repositories you own.
  • The repository owner can instead use a fine-grained token limited to sympy-contributor-dashboard with Contents: Read-only (plus Actions: Read and write for the Refresh button).

The token only ever goes to api.github.com. Without "remember" it is kept for this browser tab only. If you choose to remember it, it is kept in this browser's storage for the www.asmeurer.com origin, which is shared with the other GitHub Pages sites of that account, so prefer "Sign out" in the dashboard on shared machines.
