# SymPy contributor dashboard (loader)

This is the public loader page for the private
[asmeurer/sympy-contributor-dashboard](https://github.com/asmeurer/sympy-contributor-dashboard)
repository, served at <https://www.asmeurer.com/sympy-dashboard/>. It contains no data: with a GitHub
token that can read the private repository it fetches the dashboard code and data from there.

It is published from `site/` in that repository with `scripts/publish-loader.sh`; edit it there.
